# CodeSmith

CodeSmith is an Android home-screen launcher whose home screen is a year of day boxes.
This repository is **setup only**: it builds and runs a blank dark screen, with the native
launcher plumbing, storage schema, state, and folders ready for features.

- App label: **CodeSmith**
- Android package: `com.codesmith.launcher`
- Expo SDK 58, React Native 0.88, TypeScript
- Development build (`expo-dev-client`), not Expo Go
- Android only

## Requirements

- [Bun](https://bun.sh) 1.3+
- JDK 17 or newer (JDK 21 is fine)
- Android Studio / Android SDK with platform 36 and build-tools 36
- An Android emulator or a USB-connected device with USB debugging enabled

Make sure `ANDROID_HOME` points at your SDK and `JAVA_HOME` points at your JDK. For the
Android Studio bundled JDK, that is usually `~/develop/android-studio/jbr` on Linux or
`/Applications/Android Studio.app/Contents/jbr/Contents/Home` on macOS.

## Install

```bash
bun install
```

## Run

```bash
# Generate android/ from app.json and the config plugin (first time, or after
# changing app.json / plugins).
bun run prebuild

# Build the development client and install it on the running emulator/device.
bun run android
```

`bun run android` starts Metro and installs the debug build. If no device is attached,
start an emulator first:

```bash
$ANDROID_HOME/emulator/emulator -list-avds
$ANDROID_HOME/emulator/emulator -avd <name>
```

The app opens to a blank dark screen. That is the expected setup state.

## Set CodeSmith as the default launcher

After the app is installed, press the Home button. Android shows the choose-your-home-app
dialog; select **CodeSmith** and **Always**.

You can also set it from Settings:

1. Settings > Apps > Default apps > Home app
2. Select **CodeSmith**

Or from a terminal:

```bash
adb shell cmd package set-home-activity com.codesmith.launcher/.MainActivity
```

To go back to the stock launcher, choose it in the same Home app setting.

## Verify the launcher manifest

After `bun run prebuild`, check the generated manifest:

```bash
grep -nE 'HOME|DEFAULT|launchMode|queries' android/app/src/main/AndroidManifest.xml
```

You should see `android.intent.category.HOME`, `android.intent.category.DEFAULT`,
`android:launchMode="singleTask"`, and a `<queries>` block with the LAUNCHER intent.

## Scripts

| Script                  | Description                                      |
| ----------------------- | ------------------------------------------------ |
| `bun run start`         | Start Metro for the development build            |
| `bun run android`       | Build and install the Android development build  |
| `bun run prebuild`      | Generate the native `android/` project           |
| `bun run typecheck`     | TypeScript check with `tsc --noEmit`             |
| `bun run lint`          | ESLint                                           |
| `bun run format`        | Prettier write                                   |
| `bun run format:check`  | Prettier check                                   |

## Project layout

```
src/app/          entry and root layout
src/components/   YearGrid, YearCounter, DaySheet, TodayStrip, Dock, AppDrawer
src/db/           SQLite client and schema
src/store/        Zustand stores
src/domain/       day-status and year-stats types
src/native/       launcher-apps TypeScript wrapper
src/theme/        design tokens
modules/launcher-apps/   local Kotlin Expo module
plugins/withLauncher.js  HOME intent / queries config plugin
docs/design/      drop Stitch screens here
docs/ARCHITECTURE.md
```

The `android/` folder is generated by prebuild and is gitignored. The local module in
`modules/launcher-apps` is autolinked; rebuild the app after changing Kotlin code.
